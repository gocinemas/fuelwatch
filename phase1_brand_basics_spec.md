# Intel Phase 1: Brand Basics Only

## What We Show (Real Data Only)

### Section 1: Brand Fundamentals
- **Description** — from Wikipedia/Wikidata (1-2 sentences)
- **Founded** — from Wikidata (year only)
- **Headquarters** — from Wikidata (city, country)
- **Website** — from Wikidata (official domain)
- **Parent Company** — from Wikipedia (if owned by larger corp)

### Section 2: Top Performing SKUs Globally
- **Product Name** — official name
- **Category** — skincare / beverages / snacks / etc.
- **Price** — typical retail (GBP for UK context)
- **Availability** — Amazon / Tesco / Online / Retail
- **Why it performs** — 1 line (e.g., "Market leader in moisturizers", "Best-selling variant", "Award winner")

**Data sources for SKUs:**
1. Brand official website product pages
2. Amazon best-sellers in category
3. Wikipedia "Notable products" section
4. Retailer websites (Tesco, Sainsbury's, Waitrose)
