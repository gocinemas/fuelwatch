# Together AI Setup

## 1. Sign up (free tier available)
https://www.together.ai/
- Create account, get API key from dashboard
- Free tier: $1-2 credits to test

## 2. Add to Railway env vars
TOGETHER_API_KEY = your_key_here

## 3. Models to use
- llama-3.3-70b (fast, ~$0.50/1M tokens)
- llama-3.1-8b (real-time, ~$0.10/1M tokens)

## 4. Rate limits
- No hard quotas like Groq
- Pay per token, no surprises
