# Minimalist Entrepreneur Skills

Business & strategy skills from Sahil Lavingia's "The Minimalist Entrepreneur".

## Available Skills

| Skill | Command | Use When |
|-------|---------|----------|
| **Find Community** | `/find-community` | Exploring business ideas, finding your audience |
| **Validate Idea** | `/validate-idea` | Testing if an idea is worth pursuing |
| **MVP** | `/mvp` | Deciding scope for first product |
| **Processize** | `/processize` | Delivering value by hand before code |
| **First Customers** | `/first-customers` | Getting your first 100 users |
| **Pricing** | `/pricing` | Setting or adjusting prices |
| **Marketing Plan** | `/marketing-plan` | Growth through content |
| **Grow Sustainably** | `/grow-sustainably` | Smart scaling decisions |
| **Company Values** | `/company-values` | Defining culture & hiring |
| **Minimalist Review** | `/minimalist-review` | Gut-checking any decision |

## For Miru

**Recommended starting points:**
- `/find-community` — Who are your target users? (WhatsApp users in UK doing life admin)
- `/first-customers` — How to get initial 1000s to use Miru
- `/grow-sustainably` — When to hire, scale, or focus

## How to Use

In Claude Code, run any skill directly:
```
/first-customers
```

Then describe your situation and the skill will guide you through the strategy.
