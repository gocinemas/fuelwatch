QUALITY STANDARDS (Non-Negotiable)
═══════════════════════════════════════════════════════════════════════════════

Every numeric field MUST have:
  ✅ Value (actual data from published source)
  ✅ Source (name: "SEC Edgar 10-K", "Yahoo Finance", etc.)
  ✅ Source URL (link to where data came from)
  ✅ Confidence Score (0-100, based on source quality)
  ✅ Notes (context about collection method)

Confidence Scoring:
  95% ..................... SEC Edgar, Companies House, Official Annual Reports
  85% ..................... Wikipedia, Wikidata, Yahoo Finance, Official Websites
  75% ..................... Industry Reports, Statista, Analyst Research, News
  60% ..................... Secondary Sources, Older Data
  0% (DO NOT USE) ........ Estimates, AI-generated, Fabricated, Unverifiable

What NOT to Do:
  ❌ Never estimate values (use "Not Available - Source Not Found" instead)
  ❌ Never use ChatGPT/Claude/AI to generate data
  ❌ Never use third-party follower trackers (use @brand official accounts only)
  ❌ Never leave NULL values (must be filled or marked "Not Available")
  ❌ Never include data without source URL
  ❌ Never use news speculation without verification
  ❌ Never mix data from unverified sources
