🎨 Build Your Personal Portfolio

Step-by-step guide to create a portfolio with GitHub + Supabase + Railway

1️⃣ GitHub Setup

Create your portfolio repository on GitHub.

git init my-portfolio
cd my-portfolio
git remote add origin https://github.com/YOUR_USERNAME/my-portfolio
→ Full Guide

2️⃣ Supabase Database

Set up your database for portfolio data (projects, skills, blog posts).

npm install @supabase/supabase-js
export SUPABASE_URL=your_url
export SUPABASE_KEY=your_key
→ Full Guide

3️⃣ Deploy to Railway

Go live with your portfolio on Railway.

railway link
railway up
✓ Live at your-domain.railway.app
→ Full Guide

💻 Project Structure

Here's how to organize your portfolio:

my-portfolio/
├── src/pages/
├── public/assets/
├── supabase.js
├── railway.json
└── README.md

📝 Your First Project

Add your first project to your portfolio:

// supabase.js
const { data } = await supabase
.from('projects')
.insert({
title: 'My AI App',
description: 'Built with Claude API'
})

🚀 Go Live!

Your portfolio is now live. Start adding projects!
