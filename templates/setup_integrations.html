🔗 Integration Guide

Connect GitHub, Supabase, and Railway for a complete portfolio platform

1. GitHub Setup

Step 1: Create a repository
Go to github.com/new and create a new repository
Repository name: my-portfolio
Description: My AI-powered portfolio
Public (so employers can see it)
Step 2: Clone & initialize
git clone https://github.com/YOUR_USERNAME/my-portfolio
cd my-portfolio
npm init -y
Step 3: First commit
git add .
git commit -m "Initial commit: portfolio setup"
git push origin main

2. Supabase Database

Step 1: Create Supabase project
Go to supabase.com → Sign up → Create new project
Step 2: Get your credentials
Project Settings → API → Copy SUPABASE_URL and SUPABASE_KEY
Step 3: Create tables
CREATE TABLE projects (
id SERIAL PRIMARY KEY,
title TEXT,
description TEXT,
live_url TEXT
);
Step 4: Environment variables
echo "SUPABASE_URL=your_url" > .env
echo "SUPABASE_KEY=your_key" >> .env

3. Railway Deployment

Step 1: Install Railway CLI
npm install -g @railway/cli
Step 2: Link to Railway
railway login
railway link
Step 3: Deploy
railway up
✓ App deployed to railway.app
Step 4: Auto-deploy from GitHub
Railway Dashboard → Connect GitHub → Select your repository

✅ You're Ready!

Your portfolio is now live with:

  • ✓ GitHub version control
  • ✓ Supabase database for dynamic content
  • ✓ Railway deployment (live to the world)
  • ✓ Auto-deployment on every git push
