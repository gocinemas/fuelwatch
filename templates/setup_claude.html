🚀 Claude CLI Setup Guide

Interactive step-by-step installation for beginners

Step 1 of 5
📋 Step 1: Check Requirements
Before installing Claude CLI, make sure you have the basics installed.
✅ Node.js v18+ (download from nodejs.org)
✅ npm or yarn installed
✅ A text editor (VS Code, Cursor, etc)
✅ Git (download from git-scm.com)

Check if you have Node.js installed:

node --version

Check if you have npm installed:

npm --version

✓ Ready to Continue?

Node.js v18+ installed
npm installed
Text editor ready

❌ Troubleshooting

Q: Command not found (node/npm)
A: Restart your terminal after installation, or add Node to PATH
Q: Old Node version?
A: Download latest from nodejs.org or run: brew install node (Mac)
⚙️ Step 2: Install Claude CLI
Install the Claude CLI tool globally on your system.

Run this command in your terminal:

npm install -g @anthropic-ai/claude-cli
installing packages...
✓ @anthropic-ai/claude-cli@latest
✓ added 45 packages

Wait 1-2 minutes for installation to complete.

❌ Troubleshooting

Q: Permission denied?
A: Add sudo: sudo npm install -g @anthropic-ai/claude-cli
Q: Installation stuck?
A: Press Ctrl+C and try: npm cache clean --force
✅ Step 3: Verify Installation
Check that Claude CLI installed correctly.

Run this command:

claude --version
claude/2.1.0 (darwin-arm64)
✓ Successfully installed

You should see a version number. If you do, installation is complete!

✓ Installation Verified

Version command returns a number

❌ Troubleshooting

Q: Command not found
A: Restart terminal or check npm: npm list -g @anthropic-ai/claude-cli
🔑 Step 4: Get Your API Key
Set up authentication with Claude.

1. Go to: https://console.anthropic.com/keys

2. Click "Create API Key"

3. Copy your key (looks like: sk-ant-...)

4. Run this command and paste your key:

claude auth login
Enter your Claude API key:
sk-ant-...
✓ Authentication successful

❌ Troubleshooting

Q: Invalid API key
A: Make sure you copied the full key from console.anthropic.com
🎉 Step 5: Your First Command
Test Claude CLI with your first query!

Run a simple test:

claude "What is AI?"
$ claude "What is AI?"
AI (Artificial Intelligence) is...
[Claude responds here]

🎊 You're done! Claude CLI is ready to use.
