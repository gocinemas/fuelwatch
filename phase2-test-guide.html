Test 2: Module Gating API 📡

A) Load Default Modules

curl http://localhost:8080/api/user/modules?token=test | jq

✅ Expected Response:

{ "ok": true, "modules": { "trains": true, "fuel": true, "schools": true, "expense": true, "local": true, "research": true, "library": true, "gigs": true, "weather": true }, "count_enabled": 9, "count_total": 9 }

B) Save Custom Preferences

curl -X POST http://localhost:8080/api/user/modules?token=test \ -H "Content-Type: application/json" \ -d '{"modules": {"trains": true, "fuel": true, "schools": false, "expense": false, "local": true, "research": true, "library": false, "gigs": false, "weather": true}}'

✅ Expected Response:

{ "ok": true, "modules": { "trains": true, "fuel": true, "schools": false, "expense": false, "local": true, "research": true, "library": false, "gigs": false, "weather": true }, "count_enabled": 5, "count_total": 9 }

C) Load Again (Verify Saved)

curl http://localhost:8080/api/user/modules?token=test | jq '.modules'

✅ Expected Response:

{ "trains": true, "fuel": true, "schools": false, "expense": false, "local": true, "research": true, "library": false, "gigs": false, "weather": true }
