## Research Strategy

### Phase 1A: Quick Lookup (Wikipedia + Official Websites)
- Founded year ✓ (Wikipedia)
- Headquarters ✓ (Wikipedia)
- Parent company ✓ (Wikipedia)
- Website ✓ (Official)
- Basic positioning ✓ (Wikipedia + official site)

### Phase 1B: Market Data (Retailer Sites)
- Current pricing in each market ✓ (Tesco UK, Walmart US, Amazon India)
- Distribution channels ✓ (Where to buy sections)
- Product range ✓ (Product pages)

### Phase 1C: Category Growth (Free Market Data)
- Category growth rates ✓ (GlobalData summaries, Trading Economics)
- Market status ✓ (Emerging/mature assessment based on growth)

### Phase 1D: Segment & Targeting (Company Positioning)
- Target demographic ✓ (LinkedIn, official marketing)
- Segment size ✓ (Estimates from World Bank data)
- Income tier ✓ (Pricing positioning logic)

## Quality Checklist Per Record

- [ ] Founding year verified (Wikipedia)
- [ ] Headquarters verified (Wikipedia or official)
- [ ] Parent company verified (Wikipedia)
- [ ] Website working/correct
- [ ] Positioning tier matches pricing logic (mass-market brands cheaper, premium tier higher)
- [ ] Target demographic plausible for category + positioning
- [ ] Segment size reasonable for market (UK ~8M per segment, US ~40M, India ~20-30M)
- [ ] PPP index correct (GB/US = 1.0, India = 0.25)
- [ ] Pricing PPP-adjusted (India prices ~4-5x lower in nominal terms)
- [ ] Distribution channels verified (at least 3 per market)
- [ ] Category growth CAGR realistic for category + market
- [ ] Sources documented
